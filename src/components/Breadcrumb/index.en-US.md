# Breadcrumb

Breadcrumb navigation for hierarchical paths. API aligns with `TabBar.Tabs` (`value`, `list`, `separator`, `onChange`, etc.).

## When to use

- Show hierarchy and navigate to ancestor levels
- Do not use for peer tab switching; use `TabBar.Tabs` instead
