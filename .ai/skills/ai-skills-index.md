# Skills

| skill                | 用途                                                                 |
| -------------------- | -------------------------------------------------------------------- |
| `develop`            | 查 docs 写/改 UI；含在已有页插入库组件                               |
| `create-page-list`   | 创建列表页面（自包含问答与生成；有 react-router 时自动注册路由）     |
| `create-page-edit`   | 创建新增编辑页面（自包含问答与生成；有 react-router 时自动注册路由） |
| `create-page-detail` | 创建详情页面（自包含问答与生成；有 react-router 时自动注册路由）     |
| `create-page-login`  | 创建登录页面（自包含问答与生成；有 react-router 时自动注册路由）     |
| `sync-ai-docs`       | 从 src 同步、更新 `.ai/docs`                                         |
| `rn-to-h5`           | 问答收集 RN/H5 页面路径并迁移为优先复用 docs 能力的 H5 实现          |
| `grill-me`           | 用追问收紧方案或设计（需用户明确点名）                               |
